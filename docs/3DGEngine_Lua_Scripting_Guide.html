Scripting in Lua

The no-rebuild scripting backend — the API, worked examples, and when to reach for it instead of C++.

The game tutorials (Coin Rush, Arena Assault, Cloud Climber) use native C++ scripts. This guide is their Lua counterpart: how the Lua backend works, the complete Engine API, gameplay recipes written in Lua, and an honest map of what Lua can and can't do versus C++. 1. The Lua backend

A script can be a native C++ class (compiled into the game module) or a Lua file. They share the same lifecycle and attach the same way; the difference is iteration speed and reach.

Native C++ scriptLua script
FileContent/Scripts/Name.hContent/Scripts/Name.lua
Change → runRecompile the game moduleEdit & play — no rebuild
ReachFull engine: any component, triggers, save slots, raycastsThe curated Engine API (this guide)
Best forHot paths, deep systems, shipping-critical logicFast iteration, gameplay glue, designer tweaks

Both run in Editor Play and in packaged builds. A single object can even mix native and Lua scripts. Use Lua to prototype quickly, then move anything performance-critical (per-frame work over many entities) or anything needing triggers/save-slots to a C++ script.

The mental model A Lua script is four optional global functions (OnCreate, OnUpdate, OnFixedUpdate, OnDestroy) that call into a global Engine table. That's the whole surface.

2. Creating a Lua script

Editor 
1. Select an object → Inspector → + Add Script.
2. Set the language to Lua, name it (e.g. Coin) → Create + Attach.
   A file Content/Scripts/Coin.lua is generated with the four lifecycle stubs.
3. Edit Coin.lua (built-in editor or your text editor) and Save.
4. Press Play — the change runs immediately. No compile step.

The generated stub

Lua 
-- Coin.lua  — runs in Editor Play and packaged games without rebuilding.

function OnCreate()
    -- Called once when this object enters Play mode.
end

function OnUpdate(dt)
    -- Once per rendered frame (variable dt). Example: Engine.Translate(0, 0, dt)
end

function OnFixedUpdate(dt)
    -- Per physics step (fixed dt). Put movement / collision-facing logic here.
end

function OnDestroy()
    -- Called before this object or script is removed.
end
Key codes Lua input takes raw GLFW key numbers. Define a small table at the top of your script for readability:
local Key = { W=87, A=65, S=83, D=68, Space=32, F=70, Up=265, Down=264, Left=263, Right=262 }

3. Gameplay recipes in Lua

The same mechanics from the C++ tutorials, written in Lua. Because Lua has no trigger-event API, pickups and contact use distance checks (Engine.GetPosition + Engine.FindObject) — a common, perfectly good pattern.

A collectible coin (bob + distance pickup)

Lua 
local t = 0
function OnUpdate(dt)
    t = t + dt
    Engine.Translate(0, math.sin(t * 3.0) * dt * 0.3, 0)   -- gentle bob
end
function OnFixedUpdate(dt)
    local player = Engine.FindObject("Player")
    if not player then return end
    local px, py, pz = Engine.GetPosition(player)
    local x,  y,  z  = Engine.GetPosition()               -- no arg = self
    local dx, dy, dz = px - x, py - y, pz - z
    if dx*dx + dy*dy + dz*dz < 1.5 * 1.5 then              -- within reach
        Engine.AddScore(1)
        Engine.PlayAudioCue("Content/SFX/coin.wav")
        Engine.BurstParticles(16)
        Engine.DestroySelf()
    end
end
No rotation setter in Lua The Lua API can Translate and SetPosition/SetScale but not set rotation. For a spinning coin, either accept the bob (above), drive the spin from the animation graph, or use a C++ script (which has full transform access).

Firing a projectile

Spawn a prototype that carries a Projectile component, then configure it — the projectile system handles motion, hit detection, and damage for you.

Lua 
local Key = { Up=265, Down=264, Left=263, Right=262 }
local cooldown, fireRate = 0, 0.15
local aimX, aimZ = 0, -1

function OnUpdate(dt)
    local ax, az = 0, 0
    if Engine.IsKeyDown(Key.Up)    then az = az - 1 end
    if Engine.IsKeyDown(Key.Down)  then az = az + 1 end
    if Engine.IsKeyDown(Key.Left)  then ax = ax - 1 end
    if Engine.IsKeyDown(Key.Right) then ax = ax + 1 end
    local firing = (ax ~= 0 or az ~= 0)
    if firing then
        local len = math.sqrt(ax*ax + az*az)
        aimX, aimZ = ax / len, az / len
    end
    cooldown = cooldown - dt
    if firing and cooldown <= 0 then
        local x, y, z = Engine.GetPosition()
        local b = Engine.SpawnFromObject("Bullet", x + aimX*0.8, y + 0.8, z + aimZ*0.8)
        if b then
            -- entity, dirX,dirY,dirZ, speed, damage, range
            Engine.ConfigureProjectile(b, aimX, 0, aimZ, 26, 34, 40)
        end
        Engine.PlayAudioCue("Content/SFX/shoot.wav")
        Engine.BurstParticles(6)
        cooldown = fireRate
    end
end

An enemy: contact damage & death reward

Lua 
local hitCooldown = 0
function OnFixedUpdate(dt)
    if Engine.GetHealth() <= 0 then                        -- self is dead
        Engine.AddScore(10)
        Engine.BurstParticles(30)
        Engine.PlayAudioCue("Content/SFX/explode.wav")
        Engine.DestroySelf()
        return
    end
    hitCooldown = hitCooldown - dt
    local player = Engine.FindObject("Player")
    if player and hitCooldown <= 0 then
        local px, py, pz = Engine.GetPosition(player)
        local x,  y,  z  = Engine.GetPosition()
        local dx, dy, dz = px - x, py - y, pz - z
        if dx*dx + dy*dy + dz*dz < 1.5 * 1.5 then
            Engine.Damage(player, 12)                     -- Damage(entity, amount)
            hitCooldown = 0.6
        end
    end
end

A melee attack keyed to an animation event

Lua 
local Key = { Space = 32 }
function OnUpdate(dt)
    if Engine.WasKeyPressed(Key.Space) then Engine.PlayActionClip("Attack") end
    if Engine.WasAnimationEvent("hit") then                -- fires on the authored frame
        local g = Engine.FindObject("Guard")
        if g then
            local gx, gy, gz = Engine.GetPosition(g)
            local x,  y,  z  = Engine.GetPosition()
            local dx, dy, dz = gx - x, gy - y, gz - z
            if dx*dx + dy*dy + dz*dz < 2.2 * 2.2 then Engine.Damage(g, 50) end
        end
    end
end

Waves, saving, winning & juice

Lua 
-- Wave spawner: call a named global on a repeating timer.
function SpawnEnemy()
    local a = math.random() * 6.2831853
    Engine.SpawnFromObject("Enemy", math.cos(a) * 16, 0, math.sin(a) * 16)
end
function OnCreate() Engine.SetTimerByFunctionName("SpawnEnemy", 1.5, true) end   -- repeat

-- The flat store is strings; wrap it for numbers.
local function saveInt(k, v) Engine.SaveValue(k, tostring(v)) end
local function loadInt(k, fb) return tonumber(Engine.LoadValue(k, tostring(fb or 0))) or (fb or 0) end

function OnUpdate(dt)
    if Engine.GetScore() >= Engine.GetFieldInt("scoreToWin", 20) then
        saveInt("best", math.max(loadInt("best", 0), Engine.GetScore()))
        Engine.Win()                                        -- GameMode → HUD end screen
    end
end

4. The Engine API reference

Every function is a member of the global Engine table. Entity handles are integers (returned by FindObject/Spawn…, or nil). Functions that take an optional entity default to the script's own object.

World & transform

Engine.Self()This entity's handle.
Engine.Log(msg)Print to the console.
Engine.FindObject(name)Entity by name, or nil.
Engine.GetPosition([e]) → x,y,zPosition (self if no arg).
Engine.SetPosition([e,] x,y,z)Set position.
Engine.Translate(dx,dy,dz)Move self by a delta.
Engine.GetScale([e]) / SetScale([e,] x,y,z)Scale.
Engine.GetForward([e]) → x,y,zFacing vector.
Engine.SocketPosition(name) → x,y,zWorld position of a character socket.

Spawn / destroy / projectiles

Engine.SpawnEmpty(name, x,y,z)New bare entity → handle.
Engine.SpawnFromObject(prototype, x,y,z)Clone a scene prototype → handle.
Engine.ConfigureProjectile(e, dx,dy,dz, speed, dmg, range [,radius,owner])Aim a spawned Projectile; the projectile system moves it and applies damage.
Engine.Destroy(e) / Engine.DestroySelf()Queue destruction.

Input

Engine.IsKeyDown(k) / WasKeyPressed(k)Keyboard (GLFW codes).
Engine.IsMouseButtonDown(b) / WasMouseButtonPressed(b)Mouse buttons.
Engine.MouseDelta() → dx,dyMouse movement this frame.

Health, score & game state

Engine.GetHealth([e]) / GetMaxHealth([e])Read HP.
Engine.Damage([e,] amount) / Heal([e,] amount)Change HP.
Engine.AddScore(n) / GetScore()GameMode score.
Engine.Win() / Lose() / ResetGame()End / reset the run.
Engine.GetGameState() / GetElapsed()State name / elapsed time.

Animation, audio, particles, camera

Engine.SetAnimationParameter(name, v) / SetAnimationBool(name, b) / SetAnimationTrigger(name)Drive the controller.
Engine.PlayActionClip(name) / IsAnimationActionPlaying()One-shot actions.
Engine.WasAnimationEvent(name)Notify fired this frame.
Engine.PlayAudio([e]) / StopAudio([e]) / PlayAudioCue(path [,spatial])Sound.
Engine.LoadAdaptiveMusic(path) / SetMusicState(name)Adaptive music.
Engine.PlayParticles([e]) / StopParticles([e]) / BurstParticles([e,] n)Effects.
Engine.ShakeCamera(intensity, duration, freq)Camera shake.
Engine.PlayCameraSequence(name) / IsCameraSequencePlaying() / WasCameraSequenceEvent(seq, ev)Cutscenes.

Fields, saving, flow, time & timers

Engine.GetFieldFloat/Int/Bool/String/Vec3/Color/Entity/Asset(name [,fallback])Inspector-exposed tunables.
Engine.SaveValue(key, str) / Engine.LoadValue(key [,fallback])Flat string key/value store.
Engine.RequestSceneLoad(path) / RequestLevelLoad(l) / RequestLevelUnload(l)Scene & streaming flow.
Engine.SetTimerByFunctionName(fn, sec, repeat) / ClearTimer(id) / ClearTimerByFunctionName(fn) / IsTimerActive(id|fn)Timers call a named global Lua function.
Engine.SetGlobalTimeDilation(x) / GetGlobalTimeDilation() / GetEffectiveTimeDilation()Slow-mo.
Engine.HitStop(sec) / IsHitStopActive()Impact freeze.
Spline: Engine.SplinePointCount, GetSplinePoint, SetSplinePoint, AddSplinePoint, SplinePositionAt, SplineTangentAt, …Read/edit spline objects.

5. Lua vs C++ — choosing, and the gaps

Lua covers most gameplay glue. A few capabilities are C++ only today; reach for a native script when you need them:

CapabilityLuaC++Lua workaround
Set rotation / rotate an object—✔ full TransformBob via Translate; spin via the animation graph
Trigger enter/exit/touch events—✔ WasTriggerEnteredDistance checks (as in the recipes above)
Typed saves & save slots, checkpointsstrings only✔ SaveInt/SaveGameToSlot/SaveCheckpointSaveValue + tostring/tonumber
Arbitrary components (TryGet<T>, add/remove)curated set✔ any componentUse the exposed getters/setters
Raycasts / sphere-casts—✔ PhysicsWorldDistance/geometry math, or a C++ helper script
Sequences (Do/Wait/WaitUntil)—✔ Sequence()Timers + your own state, or coroutines
Iteration speed✔ edit & play, no rebuildneeds a recompile—
Per-frame cost over many entitieshigher (interpreted)✔ nativeKeep heavy loops in C++
Recommended split Prototype and iterate in Lua (pickups, triggers-by-distance, spawners, simple AI reactions, UI glue). Promote to C++ anything that (a) runs a heavy per-frame loop, (b) needs trigger events, raycasts, save slots, or rotation, or (c) is shipping-critical. Both live side by side on the same objects.
Reference The full C++ surface is in engine/include/engine/gameplay/Script.h; the Lua bindings are in LuaScript.cpp (the Engine table). The three genre tutorials (Coin Rush, Arena Assault, Cloud Climber) show the C++ side of these same mechanics. Print with A4 margins.
